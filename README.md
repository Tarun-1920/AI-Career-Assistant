# 🤖 AI Career Assistant

An AI-powered career assistance platform built with Python and Streamlit.  
The application helps users analyze their resumes, find suitable jobs, match their skills with job requirements, and get AI-powered career guidance.

## 🚀 Features

- 📄 Resume Analysis
- 🔍 Job Matching
- 🤖 AI Career Chat Assistant
- 🎯 Skill Analysis
- 💼 Job Recommendations
- 📊 Career Insights
- 📝 Resume-based career suggestions
- 🔐 User-friendly interface
- 🌐 Interactive Streamlit dashboard
- 🔗 Gemini API integration

## 🛠️ Technologies Used
